# infra/secrets

Запретная зона для агентов (см. `CLAUDE.md`).

- `prod.enc.yaml` — секреты прода, **зашифрованы SOPS + age**. В git лежит только шифротекст:
  ключи YAML видны, значения — `ENC[AES256_GCM,...]`.
- `prod.example.yaml` — шаблон с пустыми значениями.

Как устроено и как работать — `docs/GUIDE.md`, раздел «Секреты».
